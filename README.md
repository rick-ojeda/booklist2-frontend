
En este proyecto se desarrolla un SPA en Vue.js para gestion de libros.

Las funcionalidades son:

Registro de libros con título, autor, categoría , descripción y precio.
Filtrado de libros por título, autor,categoría y precio.
Funcionalidad de agregar/quitar libros favoritos.
Visualización del detalle de cada libro.
Cambiar el estado de un libro con imagen indicativa (Pubicado/Revision).
Cambiar el estado de la disponibilidad de un libro (Agotado/Disponible).
Edición de libros. 
Eliminación de libros.
Error 404 página no encontrada.
